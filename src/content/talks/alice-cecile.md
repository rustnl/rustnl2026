Code review is a task for trusted experts: carefully controlling quality, passing on wisdom and enforcing a coherent project vision. Right?

Not in the Bevy community! Here, review is for everyone: distributing responsibility, nurturing growth and pulling users into the open source process by asking them for feedback before features ever ship.

This talk will cover the why and how of open code review, including pitfalls to watch out for, and hopes to convince you that you can and should adopt this practice in your own projects.
