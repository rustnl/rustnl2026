Alice is a software engineer on the Android Rust team at Google, where she works
on Rust for Linux and the Tokio project. She is also an advisor to the Rust
Language team. She has written multiple Linux kernel drivers in Rust. If you
have ever searched for a question related to Rust online, you've probably seen
an answer written by Alice.
